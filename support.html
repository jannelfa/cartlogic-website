Support Topics

Support is available for:

Reporting Issues

When reporting an issue, please include:

  • Device type
  • Operating system version
  • App version
  • Screenshots if available
  • Steps to reproduce the issue

Cart Logic is actively developed and updated. Features and compatibility may evolve over time as improvements are released.
